# Напоминания для Windows 11

Настольное приложение на Python: напоминания в SQLite, окно на tkinter и уведомления Windows, которые срабатывают даже если программа свёрнута.

## Возможности

- Добавление, просмотр, удаление напоминаний
- Статусы: **Ожидает**, **Готово**, **Просрочено**, **Отменено**
- Цвета статусов в списке: ожидает — синий, готово — зелёный, просрочено — красный, отменено — тёмно-оранжевый
- Сводка над списком по всей таблице: всего, ожидает, готово, просрочено, отменено
- Фильтр списка по статусу
- Кнопка **Обновить** заново читает базу и перерисовывает список и счётчики (то же происходит при смене фильтра и после действий с напоминанием)
- Автоматический перевод просроченных из «Ожидает» в «Просрочено»
- Повторяющиеся задачи: регулярность и конечная дата
- В срок: системное уведомление Windows и всплывающее окно поверх всех окон
- Во всплывающем окне: **Готово**, **Отменено**, **Закрыть**, перенос на **10 / 30 / 60** минут или на выбранную дату и время

Пока приложение запущено (можно свернуть), проверка времени идёт в фоне.

## Повторяющиеся задачи

В форме нового напоминания можно включить повтор:

- регулярность: каждый день, каждую неделю или каждый месяц
- конечная дата (`ДД.ММ.ГГГГ`) — после неё серия заканчивается

Первое срабатывание задаётся обычными полями даты и времени и не должно быть позже конечной даты.

Кнопка **Готово** у повтора не сразу завершает задачу: ставится следующее срабатывание, если оно не позже конечной даты. Когда следующее уже за пределом — статус становится «Готово». **Отменено** останавливает всю серию.

В списке повтор виден в отдельной колонке и в карточке напоминания.

## Требования

- Windows 10 / 11
- Python 3.10 или новее
- Пакет `winotify` (тост-уведомления). Если его нет, программа пробует `win10toast`, затем PowerShell. Всплывающее окно tkinter работает в любом случае.

## Установка и запуск

```powershell
cd путь\к\dzin
python -m pip install -r requirements.txt
python main.py
```

Флаг `--add` сразу ставит курсор в поле нового напоминания:

```powershell
python main.py --add
```

База создаётся автоматически при первом запуске: файл `reminders.db` в папке проекта. Таблицы и новые поля (повтор) проверяются и добавляются, если их ещё нет.

Формат даты и времени в форме: `ДД.ММ.ГГГГ` и `ЧЧ:ММ`.

## Ярлык на рабочем столе

```powershell
python create_shortcut.py
```

На рабочем столе появится ярлык **«Напоминания»**. Он запускает программу через `pythonw` (без окна консоли) с флагом `--add` и иконкой `icon.ico`.

Если папку проекта перенесли, ярлык нужно создать заново той же командой.

## Как устроены уведомления

Каждые две секунды программа смотрит ожидающие напоминания. Если время наступило:

1. Статус становится «Просрочено»
2. Показывается системное уведомление
3. Открывается окно поверх остальных

Перенос сбрасывает статус на «Ожидает», записывает новое время и снова разрешает уведомление. Новое время должно быть в будущем и не позже конечной даты повтора, если повтор задан.

Чтобы напоминания срабатывали, процесс должен быть запущен. Закрытие окна останавливает программу.
